# วิดีโอสำหรับจอสี

คลิปปัจจุบันที่ฝังในเฟิร์มแวร์เป็น 3 วินาทีแรกของไฟล์ผู้ใช้
`W&W - OIIA OIIA (Spinning Cat).mp4` แปลงจากต้นฉบับใน Downloads โดยตรง
ที่ 10 FPS / Crop / RGB565 ไม่มีเสียง ไม่ได้ใส่ทั้งคลิป 134.73 วินาที
`oiia-cat-3s.mp4` เป็นคลิปย่อสำหรับดูบนคอมพิวเตอร์
คำสั่งสร้าง sample ด้านล่างจะเปลี่ยน header กลับไปเป็นตัวอย่างลูกบอล

`sample.mp4` สร้างขึ้นสำหรับโปรเจกต์นี้ เป็นแถบสี RGBW ลูกบอลเคลื่อนที่ และแถบสีเลื่อน
มี 30 เฟรม / 10 FPS / 3 วินาที ไม่มีเสียง

วางวิดีโอของคุณเป็น `input.mp4` หรือ GIF แล้วรันจากโฟลเดอร์โปรเจกต์:

```powershell
python tools/mp4_to_tft.py videos/input.mp4 --fps 10 --seconds 3 --strict-size
```

จะสร้างเฟรมสี 160×80 RGB565 แทนที่ `include/video_frames.h`
ใช้ Flash 25,600 ไบต์ต่อเฟรม ต้อง Build และยืนยันก่อน Upload ใหม่
MP4 อยู่บนคอมพิวเตอร์เท่านั้น จอไม่ได้ถอดรหัส MP4
