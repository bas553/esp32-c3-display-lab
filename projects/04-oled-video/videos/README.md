# ไฟล์วิดีโอต้นฉบับ

`sample.mp4` เป็นภาพเคลื่อนไหวที่สร้างขึ้นสำหรับโปรเจกต์นี้เอง: ลูกบอลเคลื่อนที่
แถบไล่ระดับเทา และพื้นเลื่อน ความละเอียด 256×128, 10 FPS, 5 วินาที
สร้างซ้ำได้ด้วย `python tools/make_sample.py` จากโฟลเดอร์โปรเจกต์

วางไฟล์ MP4 หรือ GIF ของคุณในโฟลเดอร์นี้ แล้วเรียก:

```powershell
python tools/mp4_to_oled.py videos/input.mp4 --fps 10 --seconds 5
```

ตัวแปลงสร้าง `include/video_frames.h` และไฟล์ข้อมูลสรุป `include/video_frames.json`
MP4/GIF อยู่บนคอมพิวเตอร์เท่านั้น ESP32-C3 เล่นข้อมูลภาพ 1-bit ที่ฝังในเฟิร์มแวร์
ไม่มีการคัดลอกไฟล์ MP4 ลงบอร์ด และไม่ใช้ microSD

มี header ของตัวอย่างรวมมาแล้ว จึง Build ได้ทันทีแม้ลบ MP4 ออกจากคอมพิวเตอร์
หากต้องการเปลี่ยนคลิป ต้องแปลง → Build → ยืนยันพอร์ต → Upload ใหม่

`preview.gif` เป็นภาพตัวอย่างที่ถอดกลับจากข้อมูล page buffer ใน header จริง
ขยาย 4 เท่าด้วย nearest-neighbor เพื่อให้ดูพิกเซลได้ชัด ไม่ใช่ภาพถ่ายจากจอฮาร์ดแวร์
