# ประวัติที่เก็บไว้

ไฟล์ log ในโฟลเดอร์นี้และ `projects/*/validation` เป็นผลที่บันทึกจากการทำงานเดิม ไม่ใช่การทดสอบใหม่ในวันที่เผยแพร่ มีการแทน path เครื่องด้วย placeholder เพื่อให้เผยแพร่ได้

โค้ดตัวนับปุ่มนำมาจาก `button-counter-before-game.cpp`; ตัวอย่างวิดีโอสีช่วงก่อนเพิ่มปุ่มใช้ `st7735-video-before-button-test.cpp` และ `tft-before-cat.h` ส่วนเกมและคลิปแมวมาจากโปรเจกต์ล่าสุดที่พบ

ไฟล์ทดสอบ OLED ก่อนเพิ่มปุ่มไม่มีสำเนาแยก จึงสร้างตัวอย่าง 01 ใหม่และระบุว่า reconstructed ไม่อ้างว่าเป็นต้นฉบับที่กู้คืนได้

ค่า TFT_INVERT=0 ในโปรเจกต์จอสีคือการแก้ล่าสุดที่ผู้ใช้ยืนยันว่าสีถูกต้อง ไม่ได้เปลี่ยน GPIO ของโครงการปัจจุบัน
